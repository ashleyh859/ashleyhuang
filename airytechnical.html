Project Overview

Built a full-stack mobile mental health app for college students through Dandilyonn's SEEDS nonprofit developer program. The app addresses the challenge of students needing accessible mental health support but facing barriers like stigma and limited resources.

Developed features including anonymous journaling, daily mood tracking, and motivational messaging to create a safe, judgment-free space for students to process their emotions. I handled both UX design and mobile development, from user research and wireframing to implementing the app with React Native and Firebase.

Technical Implementation

  1. Mobile development: Built cross-platform iOS/Android app with React Native and TypeScript for mood tracking and journaling features
  2. Backend integration: Implemented Firebase for real-time data storage, user authentication, and cloud functionality
  3. UX design process: Conducted user interviews, created wireframes and prototypes in Figma, performed usability testing with iterative design improvements
  4. User-centered features: Designed anonymous journaling and mood visualization to reduce stigma and encourage daily mental health check-ins
