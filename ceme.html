Project Overview

Redesigned and developed a responsive website for Cornell's Eastern Music Ensemble after they lost access to their original site. The ensemble's content was scattered across Instagram, making it difficult to showcase their mission, performances, and cultural heritage effectively.

Led the complete redesign from user research through development, creating a culturally-rich platform that highlights Eastern instruments, performances, and recruitment information. The website now serves as the ensemble's primary platform for engaging audiences and promoting East Asian musical traditions on campus.

Technical Implementation

  1. Frontend development: Built responsive website with HTML, CSS, and JavaScript featuring interactive elements including carousels, accordions, and hamburger menu navigation
  2. UX design process: Conducted user interviews with 4 participants, performed card sorting for information architecture, and iterated through multiple design versions based on user testing feedback
  3. Accessibility features: Implemented WCAG-compliant design with hover effects, animation preferences, and mobile-optimized navigation for diverse user needs
  4. Cultural design system: Created modern Chinese calligraphy theme with minimalistic color palette, hero images, and two-column layouts that reflect the ensemble's cultural identity
