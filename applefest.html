Project Overview

Redesigned the Ithaca Apple Harvest Festival website to improve user experience for one of Ithaca's largest annual community events. The original site had navigation issues and readability problems that made it difficult for visitors to find event information.

Created a fully responsive website with improved information architecture, enhanced visual design, and intuitive navigation to help both local residents and visitors discover event details, vendor information, and festival activities.

Technical Implementation

  1. Responsive design: Built mobile-first layout adapting seamlessly from narrow to wide screens for optimal viewing across all devices
  2. Interactive features: Implemented JavaScript for dynamic elements including image carousels, interactive navigation, and user engagement features
  3. Accessibility: Applied web accessibility best practices ensuring the festival information is available to all community members
